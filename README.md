# HRD 双臂机器人协同抓取仿真 (ROS 2 + Gazebo + MoveIt 2)

本项目演示了 HRD 双臂机器人在 Gazebo 物理仿真环境中，利用 MoveIt 2 C++ 接口动态规划并执行针对目标圆柱体的协同抓取任务。

## 核心亮点：双臂 TCP 目标位姿的动态几何解算

本 Demo 的核心在于 `demo_dual_arm_reach.cpp` 中的 `calc_grasp` 函数。它不依赖硬编码的固定四元数，而是采用了**基于相对三维坐标的向量几何计算法**。只要目标圆柱在公共可达工作空间内，该策略就具有极强的泛化能力。

### 1. 位置解算 (Position)
根据目标圆柱的三维绝对中心点 `(cx, cy, cz)`，结合传入的入射夹角 (`left_ang`, `right_ang`) 和手抓间隙 (`l_grasp_d`, `r_grasp_d`)：
* **入射夹角 (Approach Angle)**：代表 TCP 围绕圆柱体切入抓取的平面方位角。圆柱具有中心对称性，因此可以通过分配不同角度（如右臂 `180度` 从侧面切入，左臂 `-90度` 从正面切入），从不同方向环抱目标。
* 利用三角函数推导 TCP 在 X/Y 平面上的到达终点。
* **避障策略**：左臂的目标高度被动态赋值为 `cz + 0.13m`。这种“左高右低”的错层设定彻底避免了在此狭小空间内双臂（特别是手腕部件）发生自碰撞。

### 2. 姿态解算 (Orientation)
为了保证左、右臂 TCP 严格遵守**手心(Y)向心、手指(Z)环绕、大拇指(X)朝上**的标准抓取规范，采用了严格的三维向量正交外积（Cross Product）进行推导：
* **Y 轴 (手心向量)**：`ly(cx - bx, cy - by, cz - bz)`。包含完整的三维高低差信息，确保无论机器手臂高于还是低于目标，手心永远精准朝向圆柱体中心。
* **Z 轴 (手指向量)**：`lz = up × ly`，利用绝对垂直向上的基准向量 `up(0,0,1)` 与手心向心做叉乘，得出贴合圆柱体表面的水平切向环抱方向。
* **X 轴 (大拇指向量)**：`lx = ly × lz`，反算得出与 Y、Z 完全正交且大拇指近似向上的姿态向量。
* 构筑出完整的 `3x3` 旋转矩阵后转为四元数下发至 MoveIt 控制器。

### 3. 规划与容差参数
在动态解算出绝对完美的约束点后，MoveIt 的逆运动学 (IK) 求解器在奇异点附近可能难以获取绝对精确的值。
通过在 `plan_exec()` 中设定容差：
* `pos_tol = 0.02`: 位置容差卡紧在 2cm。
* `orient_tol = 0.2`: 姿态允许大约11度的容差，使得 OMPL 规划器在严格保持指向约束的大前提下，获得足够的采样解空间以躲避机械臂自干涉导致规划超时。

## 运行方式

1. 编译工作空间：
   ```bash
   cd ~/HRD_ws/hrd_project/hrd_ros2
   colcon build --packages-select hrd_moveit_config
   source install/setup.bash
   ```
2. 启动仿真与执行双臂规划：
   ```bash
   ros2 launch hrd_moveit_config run_cpp_demo.launch.py
   ```
